# Systemata videos
Code-rendered (no AI video generator). Brand from systematagrowth.com: emerald #0b3d2e / #0f5a43, mint #3ddc97, charcoal #1c1f1e, Inter, favicon logo mark.

Free / open-source tools: FluidSynth + FluidR3_GM soundfont (MIT) for music, SoX (reverb/mix), FFmpeg (stitch, loudness), Lucide icons (ISC), Inter (OFL), Playwright (Chromium), mido (MIDI).

```bash
npm i lucide-static && node build-icons.js   # once
OUT_DIR=/tmp/out node render.js pipeline     # also: method, engagement, join
```
